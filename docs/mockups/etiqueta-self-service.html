Notas para quem implementa

Regra de ouro: a etiqueta dos modelos atuais (40x25, 30x25, 105x21, 99x21, 58 mm) não pode mudar nem um pixel. Quem não usar "Minha medida" tem de imprimir exatamente o mesmo HTML de hoje. Fixtures byte a byte antes de mergear.

Onde fica guardado

  • Por computador: localStorage do navegador, porque a impressora é do computador. Não vai para o backend nem para a empresa (vale igual no single-company e no consolidado multi-CNPJ).
  • Por medida: o ajuste é indexado pela medida (largura x altura x colunas). Mudou a medida, o ajuste daquela medida é recarregado (ou começa em zero se nunca testou).
  • Tudo em try/catch: se o navegador bloquear o armazenamento, a função funciona na sessão e avisa "não consegui guardar neste computador".
  • Na primeira versão há uma única "Minha etiqueta" por computador. Pergunta aberta: precisa de várias?

Espaço entre etiquetas0 a 20 mm (padrão 3 mm lado a lado, 2 mm de cima para baixo)
Lado a lado1, 2 ou 3
Ajusteaté ±8 mm em cada direção; toque = 0,5 mm; ajuste fino = 0,1 mm
  • Aceitar vírgula e ponto; arredondar a 0,1 mm; mensagem de erro no campo, sem travar a digitação.
  • Ao chegar em ±8 mm: avisar e não passar disso.

Convenção do ajuste

  • Horizontal: + move para a direita, − para a esquerda. Vertical: + desce, − sobe.
  • "Saiu para a esquerda" soma +0,5 (corrige no sentido contrário). "Saiu para cima" soma +0,5 vertical.
  • O teste e a impressão real aplicam o mesmo deslocamento sobre a mesma medida.

Teste de impressão

  • Mesma função que gera o HTML da etiqueta real, mesma medida, mesmo ajuste. O conteúdo é trocado por moldura (1 mm para dentro da borda), cruz no centro e setas nas quatro bordas.
  • Imprime uma linha: uma etiqueta de teste por coluna.
  • No passo 3 a ilustração é didática: o app não enxerga o papel. A moldura começa deslocada de forma ilustrativa e anda a cada toque. Confirmar com o Caio se o texto basta ou se vale um exemplo fixo "torta para a esquerda".

Etiqueta e código de barras

  • Ajuste automático do conteúdo: se largura/altura > 2,6, layout horizontal (texto à esquerda, código à direita); senão, vertical.
  • Aviso âmbar abaixo de 25 mm de largura (código pode não ser lido). Não bloqueia, só sugere.
  • O atalho "105 x 21" é uma etiqueta única de 105 mm. O modelo atual de 3 colunas continua no seletor; para 3 colunas de 33 mm, use 33 x 21 com 3 lado a lado. Confirmar se o atalho deve preencher isso.

Padrões do app

  • Wizard no padrão TrocaModal: passos numerados no topo, Voltar/Continuar no rodapé, um assunto por passo.
  • Nada depende de hover: lápis e botões sempre visíveis, alvos de toque de 44 px ou mais.
  • Mensagens de status com aria-live; a cor nunca é o único sinal (ícone + texto).
  • Entrada: "+ Minha medida" no seletor de modelo; depois de salva vira "Minha etiqueta L x A mm" com lápis (abre o passo 1 já preenchido).
  • Sem gate de plano proposto. Confirmar antes de implementar.
